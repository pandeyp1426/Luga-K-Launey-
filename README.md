# Hima

A modern fashion storefront with collection search, saved favorites, size-aware shopping bag, and a clearly labeled checkout preview.

The application lives in [LugaKLaune](LugaKLaune/README.md). The folder is retained for compatibility with the original project; the site and package are branded Hima.

See the application README for setup, validation, image credits, and the remaining commerce integrations required before accepting real orders.
